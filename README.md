# My Portfolio

This is a personal portfolio website built with React, Vite, and Tailwind CSS. It showcases the owner's skills, experience, projects, and publications.

## Features

*   **Hero Section:** A welcoming introduction.
*   **About Me:** A section to describe yourself.
*   **Skills:** Showcase your skills and technologies you work with.
*   **Experience:** Detail your work experience.
*   **Projects:** Display your personal and professional projects.
*   **Publications:** List your publications and articles.
*   **Contact:** A form to get in touch.

## Technologies Used

*   **Frontend:**
    *   React
    *   Vite
    *   Tailwind CSS
    *   Framer Motion (for animations)
    *   GSAP (for animations)
*   **Backend (for contact form):**
    *   Node.js
    *   Express
    *   Resend (for sending emails)

## Installation and Usage

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/my-shailendra.git
    cd my-shailendra
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```
    The application will be available at `http://localhost:5173`.

## Available Scripts

*   `npm run dev`: Starts the development server.
*   `npm run build`: Builds the application for production.
*   `npm run preview`: Previews the production build locally.
*   `npm run lint`: Lints the codebase for errors.
*   `npm run format`: Formats the code with Prettier.
